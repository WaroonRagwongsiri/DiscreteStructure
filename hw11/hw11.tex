}
\begin{align}
	let \ x &= a_n \cdot 10^{n} + a_{n-1} \cdot 10^{n-1} + ... + a_1 \cdot 10^{1} + a_0
\end{align}
\subsection{Induction}
\begin{align}
	Let \ &P(n)\ be\ the\ statement: \\
	&x = 3k, k \in \mathbb{Z} \\
	&every\ n\ written\ as\ x\ and\ sum\ of\ each\ a_n\ is\ divisible\ by\ 3 \\
\end{align}
\subsubsection{P(0)}
\begin{align}
	x &= 3 \cdot 0
	x &= 0 \\
	a_0 &= 0 \\
	\sum_{i=0}^{n}
\end{align}
$\therefore$ ตัวเลขที่หาร 3 ลงตัว จะมีผลรวมเลขโดดแต่ละตัว หาร 3 ลงตัวด้วย
